# Wedding Invitation Background Images Generation Prompt
## For AI Image Generation (DALL-E, Midjourney, or similar)

### CONTEXT
Generate layered, elegant background images for wedding invitation templates. These are BASE/TEMPLATE images that will have:
- User-uploaded couple photos overlaid on top
- Dynamic text overlaid (names, dates, location, story)
- NO text baked into the image (keep it clean for text overlays)
- Designed for both desktop (16:9) and mobile (9:16) aspect ratios
- Color palette: Charcoal (#0B0F19), Ivory (#F8F4EE), Champagne (#CBB89E), Soft Blush (#E7D4C8)

## GENERATION SPECIFICATIONS (for all templates)

### File Specifications
- **Format:** PNG with transparency (RGBA)
- **Resolution:** 
  - Desktop (16:9): 1920x1080px minimum
  - Mobile (9:16): 1080x1920px minimum
- **Color Accuracy:** Ensure champagne (#CBB89E) and soft blush (#E7D4C8) are precisely matched
- **Quality:** High resolution, suitable for print (300dpi if possible)

### What NOT to include
- ❌ NO text, words, numbers, or dates
- ❌ NO couple names or initials
- ❌ NO photos of real people (reserved for user upload)
- ❌ NO hardcoded text overlays
- ❌ NO realistic faces or full bodies

### What MUST include
- ✅ Clear reserved area for photo placement (visually apparent from design)
- ✅ Clear reserved area for text placement (clean, readable background)
- ✅ Precise color palette usage
- ✅ Professional, editorial wedding aesthetic
- ✅ Mobile-optimized versions (9:16 vertical format)
- ✅ Layered composition suitable for photo + text overlay

### During Invite Creation
1. User selects a template (e.g., "Romantic Elegant")
2. System loads the base background image (16:9 or 9:16 based on device)
3. User uploads couple photos (1-2 photos)
4. System overlays:
   - Couple photos on top of base image (using Canvas API or image processing library)
   - Dynamic text (names, date, location, story) on top
5. Final composite image is generated and stored

### Image Composition Logic (Pseudo-code)
```
1. Load base background template image
2. Resize/crop user photos to fit reserved photo area
3. Overlay photos on background
4. Render text elements (names, date, location) on appropriate areas
5. Export final composite as high-quality image (PNG or JPEG)
6. Store in Supabase Storage with unique filename
```

## GENERATION WORKFLOW

### Step 1: Generate Images
Use DALL-E, Midjourney, or similar tool with the 6 prompts above (one per template).

### Step 2: Download & Organize
Download all generated images (both 16:9 and 9:16 aspect ratios if tool supports it).

### Step 3: Refine if Needed
Adjust colors, contrast, or layout in Figma or Photoshop if fine-tuning is needed.

### Step 4: Upload to Project
Add images to `/public/invite-backgrounds/` folder in the codebase.

### Step 5: Register in Database
Add template metadata to `invite_templates` table:
```sql
INSERT INTO invite_templates (name, slug, background_image_url, color_scheme, layout_config, is_public)
VALUES (
  'Romantic Elegant',
  'romantic-elegant',
  'https://[project].supabase.co/storage/v1/object/public/invite-backgrounds/romantic-elegant-16x9.png',
  '{"primary": "#CBB89E", "secondary": "#E7D4C8", "text": "#0B0F19"}',
  '{"photoArea": "left", "textArea": "right", "aspectRatio": "16:9"}',
  TRUE
);
```

### Step 6: Display in UI
Admin form shows template selector with thumbnails (preview images).
