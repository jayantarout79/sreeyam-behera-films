# Wedding Invitation Background Images Generation Prompt
## Mobile-Only Version (9:16 Vertical) - Multi-Slide Theme System

### CONTEXT
Generate layered, elegant background images for mobile wedding invitation templates. **MOBILE ONLY** (9:16 aspect ratio - portrait/vertical format).

Each template has **4 separate backgrounds** (one for each slide):
1. **Slide 1: Hero/Introduction** - Couple names, emotional opening
2. **Slide 2: Venue & Details** - Location, date, time information (VENUE-CENTRIC design)
3. **Slide 3: Story** - Couple story, personal narrative
4. **Slide 4: Closing/RSVP** - Call to action, RSVP info, closing message

**Within each theme, all 4 slide backgrounds maintain the same visual style/color palette but have different layouts & designs to keep scrolling experience engaging.**

### SPECIFICATIONS
- **Aspect Ratio:** 9:16 (Portrait/Vertical ONLY - suitable for mobile phones)
- **Resolution:** 1080x1920px minimum
- **Color Palette:** Charcoal (#0B0F19), Ivory (#F8F4EE), Champagne (#CBB89E), Soft Blush (#E7D4C8), Pure White (#FFFFFF), Warm Gray (#2F3A4B)
- **Format:** PNG with transparency (RGBA)
- **NO text baked into images** (all text overlaid dynamically)
- **Each slide: Reserved areas for text overlay** (clean, readable backgrounds)

## HOW IT WORKS IN THE SYSTEM

**During Invite Creation:**
1. User selects template (e.g., "Romantic Elegant")
2. System loads 4 slide backgrounds for that template
3. User fills form with couple info
4. **Slide-by-slide rendering:**
   - Slide 1: Uses `slide-1-hero.png` + overlays couple photos + couple names
   - Slide 2: Uses `slide-2-venue.png` + overlays event date, time, location, address, venue name
   - Slide 3: Uses `slide-3-story.png` + overlays couple story text
   - Slide 4: Uses `slide-4-closing.png` + overlays RSVP info, closing message
5. **Final invite:** 4 scrollable slides, each with distinct background but cohesive theme
